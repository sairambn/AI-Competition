# Solutions

Each team adds **one folder** here via Pull Request.

```text
solutions/
  Code-Warriors/
    README.md
    ...app code
  Team-Alpha/
    README.md
    ...
```

## Team README template

```markdown
# Team Name

**Problem:** (title + id)
**Live URL:** https://…
**Contact:** team@email

## Run locally

npm install
npm run dev

## Notes

What we built in 2 hours…
```

## PR title

```text
[Solution] Team-Name — Problem title
```

Only add/edit your team folder. Do not change site source under `src/`.
